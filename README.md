## ✨ Что это?

**Zerocloud** — минималистичный веб-интерфейс, который превращает **GitHub Releases** в полноценное облачное хранилище.

Загружай любые файлы через красивый интерфейс — они автоматически появятся в релизах выбранного репозитория. Без серверов, без регистрации, без лимитов (кроме лимитов самого GitHub).


## 🚀 Возможности

| Функция | Описание |
|--------|----------|
| ⚡ **Мгновенная загрузка** | Файлы отправляются напрямую в GitHub Releases |
| 🔄 **Два режима** | Автоматический и ручной (с кастомным тегом и именем) |
| 🎨 **Современный дизайн** | Тёмный интерфейс с плавной анимацией |
| 🔒 **Безопасность** | Токен хранится только в браузере (не отправляется никуда, кроме GitHub) |
| 📱 **Адаптивность** | Отлично работает на телефонах и компьютерах |

## 📦 Как использовать

1. Открой [**Zerocloud**](https://xqr4d.github.io/zerocloud/)
2. Вставь **GitHub Personal Access Token** (с правами `repo`)
3. Укажи **Owner** и **Repository**
4. Выбери файл
5. Нажми **«Загрузить и отправить»**

Готово! Файл появится в релизах твоего репозитория.

### Создание токена

1. Перейди в [GitHub → Settings → Developer settings → Personal access tokens](https://github.com/settings/tokens)
2. Создай токен с правом **`repo`**
3. Скопируй его и вставь в форму
